Backend Engineer — Python / Django

We are looking for a Backend Engineer to join our growing platform team.
You'll design and build the APIs that power our product, working closely
with frontend and data teams.

Responsibilities:
- Design, build and maintain REST APIs using Python and Django
- Write clean, tested, well-documented code
- Work with PostgreSQL/MySQL for data modelling and query optimisation
- Deploy and monitor services on AWS
- Collaborate using Git, code review, and CI/CD pipelines
- Participate in agile ceremonies (sprint planning, stand-ups, retros)

Requirements:
- 1-3 years of experience with Python and Django or Flask
- Solid understanding of SQL and relational database design
- Familiarity with REST API design principles
- Experience with Git and collaborative development workflows
- Exposure to AWS or another cloud provider
- Strong problem solving and communication skills
- Bonus: experience with Docker, CI/CD (Jenkins/GitHub Actions), or NoSQL (MongoDB)
